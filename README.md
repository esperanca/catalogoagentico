## Deploy

Via Netlify CLI (site já criado e linkado):
```bash
netlify deploy --prod --dir .
```

Ou conecte o repo no painel: https://app.netlify.com/projects/catalogoagentico → Link repository → `esperanca/catalogoagentico` (publish dir `.`).
